### 2. Կիրառված մեթոդներ և ալգորիթմներ (`Verluchutyun.cpp`)
1. **Բազմալեզու UTF-8 ապակոդավորում և գրադարձում (տրանսլիտերացիա).** հայկական (`U+0531–U+0587`), կիրիլյան (`U+0400–U+04FF`), հունական (ներառյալ պոլիտոնիկ հունարենը՝ `U+0386–U+03CE`, `U+1F00–U+1FFF`) և դիակրիտիկ նշաններով լատինական այբուբենների բերում միասնական հնչյունական լատինատառ տեսքի։
2. **Հնչյունա-ուղղագրական նորմալացում.** պատմական երկբարբառների ու տառակապակցությունների միասնականացում (`ph → f`, `th → t`, `rh → r`, `ch → kh`, `qu → k`, `x → ks`, `ae/oe → e`, հայերենի `ու → u`, բառասկզբի `h-` շնչեղության և կրկնակ բաղաձայնների համահարթեցում)։
3. **Բազմալեզու ձևաբանական սթեմինգ (արմատի անջատում).** հայերենի (`-աբանություն`, `-ագիտություն`, `-ագրություն`, `-ություն`, `-ական`, `-ային`, `-ացում`, `-ույթ`), ռուսերենի և եվրոպական լեզուների (`-ология/-ology`, `-изация/-ization`, `-ation`, `-изм/-ism/-isme/-ismus`, `-ический/-ical/-ique/-isch`, `-ikos`, `-sis`, `-us`, `-um`) վերջավորությունների շերտավոր հեռացում։

5. **Լևենշտեյնի հեռավորության կշռված մոդել.** բառերի մակերեսային ձևերի ($45\%$) և ձևաբանական արմատների ($55\%$) նմանության համակցված հաշվարկ՝ երկարությունների նախնական ֆիլտրմամբ (`compare_latin_forms_fast`) և նորմալացված ձևերի քեշավորմամբ (`std::unordered_map`)։

## 🌐 English Overview

**Lexical-Analysis** is a C++ computational linguistics tool designed to align, normalize, and compare linguistic terminology across eight languages (**Armenian, Russian, English, French, German, Spanish, Latin, and Greek**).

### Key Features
* **Automated PDF & CSV Lexicon Alignment:** Integrates three CSV lexical tables with full-text extraction from an Armenian etymological PDF dictionary using `poppler-cpp` (`raw_order_layout`).
* **Cross-Script Phonetic Transliteration & Normalization:** Converts Armenian, Cyrillic, Greek (including polytonic diacritics), and Latin scripts into a unified phonological representation.
* **Multilingual Morphological Stemming:** Strips derivational and inflectional suffixes across all eight languages to isolate core etymological roots.
* **Weighted Levenshtein Similarity Engine:** Combines surface-form similarity ($45\%$) and root-stem similarity ($55\%$) with $O(1)$ length-ratio upper-bound pruning and hash-table memoization.
